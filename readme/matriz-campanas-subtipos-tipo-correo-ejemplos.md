# Matriz Operativa: Tipo de Campana, Prioridad, Subtipo y Tipo de Correo

Este documento resume la regla operativa usada en el modulo de Campanas para sugerir el tipo de correo segun:

- tipo de campana;
- prioridad dentro del tipo (`Prioritaria` o `Secundaria`);
- subtipo de campana.

Regla general:

- dentro de cada tipo de campana, los primeros 4 subtipos son prioritarios;
- despues se listan 2 subtipos secundarios;
- la combinacion define el tipo de correo sugerido;
- el ejemplo de correo y el requisito operativo son guias editoriales para ejecucion.

Estado actual de la politica:

- la politica de compatibilidad tipo/subtipo vigente en backend sigue esta misma matriz;
- todas las combinaciones listadas en esta tabla estan habilitadas para el modulo de Campanas.

Referencias relacionadas:

- `readme/matriz-campanas-subtipos-tipo-correo.md`
- `readme/matriz-campanas-subtipos-prioridad-casos-uso.md`

## Uso recomendado

- usar esta matriz cuando el equipo de marketing necesite alinear subtipo de campana con el tipo de correo sugerido;
- usar el ejemplo de correo solo como punto de partida editorial, no como plantilla final cerrada;
- validar siempre el requisito operativo antes de programar la pieza o la automatizacion.
